连接你的 GitHub 仓库

这个后台不需要服务器：它直接读写你 GitHub 仓库里的 docs/data/db.json。
需要的 Token 是一个「只授权这一个仓库、Contents 读写」的 Fine-grained Token。
申请地址：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → 选这个仓库 → Repository permissions → Contents: Read and write。
瞬刻门户 页面装修 视频管理 文章管理 音乐管理 通知推送 字体与外观 底部导航 仓库设置
